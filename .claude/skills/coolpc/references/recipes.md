# 查件配方與配單經驗

以下 regex 都是實際在原價屋資料上驗證過的，直接餵給 `search_coolpc.py`。

## 各類查件配方

| 需求 | 指令 |
|---|---|
| 顯卡依晶片 | `search_coolpc.py 12 'RTX5060Ti-16GB'`、`'RX9070XT'`、`'RX9060XT-8G'`（群組名就是晶片型號） |
| AM4 CPU | `search_coolpc.py 4 'AM4\|5600\|5800X3D'` |
| AM5 CPU 搭板價 | `search_coolpc.py 4 '搭板'`（名稱含 `[搭板專案]`，任搭主機板即可） |
| 主機板依晶片組 | `search_coolpc.py 5 'B850 /' -x 'ITX\|開學慶\|工作站'`、`'B650' -x 'ITX\|B650E'`、`'B550\|A520' -x ITX` |
| ATX 板 | 品名含 `/ATX/`；M-ATX 含 `M-ATX` |
| DDR4 16G 雙通道 | `search_coolpc.py 6 '16G.*DDR4' -x '筆記型\|單條'` |
| DDR5 雙通道 | `search_coolpc.py 6 '32G.*DDR5' -x '筆記型\|單條'` |
| Gen4 1TB SSD | `search_coolpc.py 7 'Gen4.*(1TB\|1T)\|(1TB\|1T).*Gen4' -x '2230\|2242'`（品名有 TLC/QLC 可再過濾） |
| 電源依瓦數/牌 | `search_coolpc.py 15 '750W.*金牌\|金牌.*750W' -x SFX`；全模組加 `全模` |
| 塔散 | `search_coolpc.py 10 'AX120\|AK400\|Assassin\|Phantom\|Peerless'` |
| 機殼依品牌 | `search_coolpc.py 14 'Montech' -x '白\|SFX\|ITX'`、`'Lancool'`、`'Antec.*(C8\|FLUX\|CX)'` |
| 跨分類找型號 | `search_coolpc.py 0 '9800X3D'` |

`-x` 排除 regex 很常用：筆記型、單條、ITX、白色版、SFX、活動綁定商品（如「開學慶 … 加購」）。

## 品名裡可以直接讀到的相容性資訊

- **機殼**：`顯卡長33/CPU高16.1` → 顯卡長度上限與塔散高度上限 (cm)。
- **顯卡**：`28cm/三風扇` → 卡長。
- **塔散**：`高14.8cm`。
- **主機板**：`M-ATX` / `/ATX/` / `ITX`、`2DIMM`/`4DIMM`、`+無線`/`Wi-Fi7`、相數 `8+2+1相`、`[DDR5]` 或群組名的 `(DDR4)`/`(DDR5)`。
- **電源**：`雙8` = 兩組 CPU 8-pin (EPS)；`ATX3.1(PCIe 5.1)` = 有 12V-2x6 接頭；`金牌/銅牌`、`全模/半模/直出線`、保固年數。
- **CPU**：`(含風扇)`/`MPK` 附風扇；AMD 9000X、X3D、Intel K/KF `無風扇` 要另配散熱器；`無內顯`/`F` 版一定要配獨顯。
- **記憶體**：`雙通8GB*2` 雙通道；`單條` 為單支；`筆記型` 是 SO-DIMM 別選。

配單時至少核對：CPU 腳位 ↔ 主機板群組、主機板 DDR 世代 ↔ 記憶體、顯卡長 ≤ 機殼顯卡長、塔散高 ≤ 機殼 CPU 高、瓦數 ≥ 顯卡 TBP + CPU + 150W 餘裕。

## 條件價規則

- `搭板專案`：CPU 與任一主機板同購即可，估價單一定要有主機板。
- `裝機價` / `組裝價` / `限搭機` / `限組裝`：整機組裝才適用；配整機時可直接用，比一般價低。
- `任搭折N`：估價頁未扣，`quote.py` 會在總計下方另列合計與實付估計。
- `限購N`：套裝加購限量商品，一般配單不用。
- `訂購` / `【訂】`：非現貨，交期要問。

## 2026-09 行情筆記（會過期，僅供比例參考）

- 記憶體飆漲：DDR5 16G 雙通道只剩 UMAX 一款 (8,200)，32G 從 14,500 起；DDR4 16G 雙通道 4,450。低預算走 AM4+DDR4 省最多的就是記憶體。
- 顯卡 CP 值：RX 9060XT 8G ≈ 11k、RX 9060XT 16G ≈ 14.6k、RX 9070 GRE 12G ≈ 18–20k、RX 9070XT ≈ 26k；同級 NVIDIA 貴 3–5k，RTX 5070Ti 起跳 45k（限搭機）。
- CPU 甜蜜點：R5 5600X 含風扇 4,790 (AM4)、R5 7500F 搭板 4,490 (AM5)、R7 9800X3D 搭板 15,000。
- 電源：保銳 CyberG II 750W/850W 金牌全日系 7 年 2,090/2,390 是穩定的預設選擇。
