# 估價網站介面與驗收

建立新站或改版網頁時讀取本文件。資料結構與價格規則見 [site.md](site.md)；介面調整沿用既有 `CoolPC` 對照、計價與編解碼。

## 模板與客製

- `templates/index.html` 為介面及事件，`templates/builder.css` 為樣式，`templates/coolpc-live.js` 為報價核心。`build_site.py --init` 將三者放入 `docs/`，一般資料生成只寫 `docs/data.json` 與 `docs/data-more.json`。
- 新站預設使用石墨黑背景、深灰面板、青藍重點色與數字對齊；既有站依使用者已選定的風格調整，不因同步模板而強制重設。
- `--init` 保留已存在的檔案；更新既有站時明確合併 HTML 與 CSS。`--force` 會連設定、Worker 與 workflow 一起覆寫，只用於已確認要完整重建的情境。
- 模板使用通用標題與相對資源路徑。設定 `site.json` 後，同步初始 HTML 的 title、h1、簡介、description 與 OG 標題／描述；正式 URL 確認後再加 canonical、`og:url`。模板不帶特定專案的網域或 GitHub 連結。

## 布局與操作

- 頁首簡介、報價日期／快照來源 → 起始方案卡 → 零件清單與估價摘要 → 說明與頁尾。方案價格是未修改預設內容的總計；摘要是目前估價單。
- 桌面 ≥1024px 採雙欄，右側摘要 `position: sticky`；較窄畫面為單欄與底部總價／分享列。保留底部空間與 safe-area，避免固定列蓋住內容。
- 零件列顯示完整品名、條件標籤、數量、單價／小計、替換與移除；空欄顯示新增入口，所有欄位皆可空著。
- 「02 打造你的配置」下方有「主機零件｜全部分類」開關 (`site.json` 的 `all_categories: false` 時不顯示)。預設主機零件，畫面與過濾都和純主機站相同；切到全部分類出現「03 其他商品」與新增按鈕，可加原價屋全部 30 類任意多件。關掉開關只藏新增按鈕，已選的其他商品照樣列出並計價。
- 「更換／新增」開原生 `<dialog>`，桌面為右側面板、手機為全螢幕。依 slot 的分類集合讀取原價屋型錄，保留群組及順序，以品名或群組關鍵字比對；無結果顯示文字提示。
- 開啟時焦點進搜尋框；選取即套用並關閉；關閉按鈕或 Escape 不改單。面板狀態獨立於估價單重繪，關閉後回到該欄更換／新增按鈕。數量重繪也要保持焦點可追蹤。
- 沿用 `orig`／`pin`：改選別件用現價，選回原品項還原原 pin；改數量保留 pin，下架品項留原品名與報價。
- 載入／失敗畫面只在資料尚未可用時顯示，失敗有重試入口。即時更新失敗保留已載入的快照；`live_url` 空時維持停用。
- 焦點有清楚外框；價格漲跌與警告同時使用文字／符號，且支援 `prefers-reduced-motion`。

## 驗收

1. 在暫存目錄跑 `--init`，確認 HTML、CSS、JS 都存在且相對路徑能載入；再跑一次確認既有客製檔案保留。用生成的專案執行副本產出 `data.json`，避免漏掉腳本或模板相依。
2. 執行 `node --test <技能目錄>/tests/coolpc-live.test.js` 與 `python3 -m unittest discover -s <技能目錄>/tests`；JS 解析一致性測試需要專案內原始 `evaluate.php` 與解析快照，不具備時會略過該項。
3. 在 1440、1024、768、390px 檢查載入、長品名、無橫向溢出、摘要／固定列、dialog 與說明區。以瀏覽器驗收型錄最大分類，確認搜尋可用。
4. 實測方案切換、搜尋／無結果、選取／取消、移除／新增、數量 1–9、重設、焦點回復與空單提示；鍵盤實際輸入數量後離開欄位，確認 commit 計價。
   - 全部分類：預設不載 `data-more.json`；切開關才載、重新整理後記得開關；分類下拉列整類 (螢幕約 700 多件)、跨分類搜尋上限 300；同一件加兩次變數量 2；含其他商品的分享單重開會先載完整型錄，開關關著時其他商品仍列出、新增按鈕隱藏。
   - 把 `data.json` 的 `more.url` 暫時指向不存在的檔模擬載入失敗：其他商品以報價計並標「其他分類的報價載入失敗」，切開關重試成功後改回現價。測完還原。
   - 帶到原價屋估價頁：有東西的單按下去，原價屋估價頁要預選同樣品項與數量，含稅價等於網頁總計；空單只開空白估價頁；含已下架列時 toast「N 項目前查不到」。Claude Desktop 內建瀏覽器面板會把新分頁 POST 變成 GET，在面板測要把 `HTMLFormElement.prototype.submit` 包一層改 `target='_self'` (見 coolpc-pages.md)。
5. 用歷史分享單驗證舊價、▲▼、下架、改用現價、還原／選回原品項、複製清單與分享連結重開。用暫存資料或測試伺服器模擬載入失敗與重試，不改正式快照。
6. 保存桌面／手機預覽及驗收結果。區分本機通過與正式部署；更新技能不代表已推送、部署或啟用即時代理。
