# 估價網站介面與驗收

建立新站或改版網頁時讀取本文件。資料結構與價格規則見 [site.md](site.md)；介面調整沿用既有 `CoolPC` 對照、計價與編解碼。

## 模板與客製

- `templates/index.html` 為介面及事件，`templates/builder.css` 為樣式，`templates/coolpc-live.js` 為報價核心，`templates/builder-ui.js` 為搜尋／用途分類／選件預覽與套用的純 UI 邏輯。`build_site.py --init` 將四個資源放入 docs；一般資料生成只寫 data.json 與 data-more.json。BuilderUI 可由瀏覽器載入或以 CommonJS 跑 Node 測試。
- 新站預設使用石墨黑背景、深灰面板、青藍重點色與數字對齊；既有站依使用者已選定的風格調整，不因同步模板而強制重設。
- `--init` 保留已存在的檔案；更新既有站時明確合併 HTML 與 CSS。`--force` 會連設定、Worker 與 workflow 一起覆寫，只用於已確認要完整重建的情境。
- 模板使用通用標題與相對資源路徑。設定 `site.json` 後，同步初始 HTML 的 title、h1、簡介、description 與 OG 標題／描述；正式 URL 確認後再加 canonical、`og:url`。模板不帶特定專案的網域或 GitHub 連結。

## 布局與操作

- 簡短介紹、報價日期／快照來源 → 用途選擇或收合的目前配置 → 零件清單與估價摘要 → 說明與頁尾。卡片明確標「預設總計」，收合摘要與估價摘要均是目前估價單，修改後不可誤用原菜單價格。
- 桌面 ≥1024px 採雙欄，右側摘要 sticky；較窄畫面為單欄與底部總價／分享列。用 ResizeObserver 測量固定列高度，內容與 toast 依該高度留空間，列本身含 safe-area；現價標示換行後也不能蓋住最後內容。
- 零件列完整品名自然換行，數量與價格同列，保留條件／歷史價提示；空欄顯示新增入口，所有欄位皆可空著。手機更換／移除／數量控制至少 44px 點擊範圍；降低留白不靠截斷品名。
- 「02 打造你的配置」下方有「主機零件｜全部分類」開關 (`site.json` 的 `all_categories: false` 時不顯示)。預設主機零件，畫面與過濾都和純主機站相同；切到全部分類出現「03 其他商品」與新增按鈕，可加原價屋全部 30 類任意多件。關掉開關只藏新增按鈕，已選的其他商品照樣列出並計價。
- 「更換／新增」開原生 dialog，桌面為右側面板、手機為全螢幕；依 slot 或其他商品分類讀型錄。搜尋、群組、排序與價差規則見下節；無結果提供減少關鍵字或清除群組篩選的提示。
- 開啟時焦點進搜尋框；成功選取才套用並關閉，拒絕重複替換時留面板。關閉按鈕或第一次 Escape 不改單，關閉後回到該欄更換／新增按鈕。面板狀態獨立於估價單重繪；數量 1–9 的有效輸入立即計價，失焦時校正無效／空值，重繪保留輸入焦點。
- 沿用 `orig`／`pin`：改選別件用現價，選回原品項還原原 pin；改數量保留 pin，下架品項留原品名與報價。
- 載入／失敗畫面只在資料尚未可用時顯示，失敗有重試入口。即時更新失敗保留已載入的快照；`live_url` 空時維持停用。
- 焦點有清楚外框；價格漲跌與警告同時使用文字／符號，且支援 `prefers-reduced-motion`。
- 唯讀估價單 (`#v=1&q=`)：深色頁面中間一張白色紙本單據 (`.sheet` 內重新宣告同名色彩 token，既有的漲跌／下架樣式自動換成淺色版)。上方動作列：「← 編輯這張估價單」、複製估價單連結、列印／存成 PDF、帶到原價屋估價頁；紙張依序是抬頭 (QUOTATION／估價單／網站名)、估價名稱／報價日期／現價資料／品項、明細表 (項目／品名／數量／單價／小計)、合計區、備註、免責聲明。檢視模式藏起首頁簡介、報價日期列、說明與手機底部列。
- 編輯模式摘要保留含稅估價總計為主價格，桌機與手機補實付估計（current − off）；有歷史價差時標「依現價估計實付」，避免混為原報價折後價。主按鈕分享唯讀估價單，搭配預覽及次要的可編輯分享；手機固定列保持預覽與分享兩個入口。
- 估價單 ≤600px 螢幕版：名稱全寬、日期／現價資料／件數緊湊排列，明細前補含稅總計。明細一列一張：項目、完整品名、數量・單價・小計（data-label 前綴）；表頭視覺隱藏，tr／td 保留 ARIA role 與表格語意。
- 列印：檢視模式只印紙張，白底黑字、root 改 light color-scheme（否則 PDF 頁邊會是深色）、列與合計不跨頁、跨頁重複表頭。手機頂部總額只在 screen media 顯示，列印保留底部完整合計；編輯模式不印固定列。


## 起始配置

- 模板用途順序為文書、入門遊戲、主流遊戲、高階；同用途顯示既有 AMD／Intel 配置，沒有的組合不補造菜單。purpose/platform 的格式與 fallback 見 [site.md](site.md)。
- 泛用配單先讓訪客比較同用途的不同平台；若使用者另指定平台優先的客群或流程，依該要求調整，不把本次選擇泛化成所有網站的規則。
- 無有效配置網址時展開目前用途；有效 #b/#q 收合還原，唯讀連結仍直接開估價單。用途切換只篩選，不改 cur、內容或 hash；點實際配置才切換並收合，焦點回到更換配置按鈕。
- 展開時選中狀態以配置 key 對應，不能依過濾後卡片的 DOM 順序更新。更換配置展開目前用途；收合取消不改單。
- 同一次頁面保留各方案草稿，分享單另有返回入口。預設來源／組裝建議用「配置說明」收合，分享歷史漲跌、下架與條件提示保持可見；不額外加跨重新整理的草稿保存或訪客追蹤。

## 搜尋與換件價差

- 搜尋採 NFKC、大小寫正規化、空白分詞 AND；每個詞都須在品名／群組／分類組合文字中匹配。提示依分類，例如記憶體 32GB 6000、主機板 B850 WIFI；既有下架型號預填保留。
- 規格群組直接取目前型錄；保留其他商品的分類選單。每次開面板重設群組與排序，不沿用前一次隱藏條件。
- 原價屋順序保留群組標題；現價單價升／降序跨群組排列，每件補群組標籤，同價維持原順序。跨分類先完整篩選排序，再取最多 300 件，同時顯示總符合數與顯示數。
- 價差預覽共用實際 selectCandidate 規則但不改資料；基準是套用後 quoted − 目前 quoted，包含數量、歷史 pin、選回原件與其他商品合併。不扣任搭折，面板標「依目前數量計算，任搭折扣另計」。
- 替換已有的其他商品時維持拒絕與提示，不顯示數字價差；新增同件則合併數量，上限 9 時預覽增加為 0。避免只用型錄單價相減，或複製一套不同的預覽計算。

## 驗收

1. 在暫存目錄跑 `--init`，確認 HTML、CSS、coolpc-live.js、builder-ui.js 都存在且相對路徑能載入；再跑一次確認既有客製檔案保留。用生成的專案執行副本產出 `data.json`，避免漏掉腳本或模板相依。
2. 執行 `node --test <技能目錄>/tests/` 與 `python3 -m unittest discover -s <技能目錄>/tests`；JS 解析一致性測試需要專案內原始 `evaluate.php` 與解析快照，不具備時會略過該項。
3. 在 1440、1209、1024、768、390px 檢查載入、長品名、無橫向溢出、摘要／固定列、dialog 與說明區。以瀏覽器驗收型錄最大分類。此 repo 的無 hash 首頁：1209×954 首屏見首件與摘要價格，390×844 見首件開始處及固定列；各寬度無水平溢出。
4. 實測用途篩選不改單／hash、選定收合、方案／分享單草稿往返、缺 metadata 的配置、多詞／全形／無結果、群組及穩定排序、選取／取消、移除／新增、數量 1/2/9、重設、焦點與空單。價差需等於套用後總計差，含鎖價、下架、優惠結束與重複合併。
   - 部分瀏覽器工具的 fill 不等於原生 change；確認總計及 hash，不能只看 input.value。鍵盤輸入有效數量、離開欄位與第一次 Escape 關閉都要實測。
   - 測新版本或無 hash 首頁時先導航到目標，再明確 reload；同 URL／片段導航可能保留舊文件、面板或記憶體狀態。
   - 全部分類：預設不載 `data-more.json`；切開關才載、重新整理後記得開關；分類下拉列整類 (螢幕約 700 多件)、跨分類先排序再取 300，顯示完整符合數；同一件加兩次變數量 2；含其他商品的分享單重開會先載完整型錄，開關關著時其他商品仍列出、新增按鈕隱藏。
   - 把 `data.json` 的 `more.url` 暫時指向不存在的檔模擬載入失敗：其他商品以報價計並標「其他分類的報價載入失敗」，切開關重試成功後改回現價。測完還原。
   - 帶到原價屋估價頁：有東西的單按下去，原價屋估價頁要預選同樣品項與數量，含稅價等於網頁總計；空單只開空白估價頁；含已下架列時 toast「N 項目前查不到」。Claude Desktop 內建瀏覽器面板會把新分頁 POST 變成 GET，在面板測要把 `HTMLFormElement.prototype.submit` 包一層改 `target='_self'` (見 coolpc-pages.md)。
5. 用歷史分享單驗證舊價、▲▼、下架、改用現價、還原／選回原品項、複製清單與分享連結重開。用暫存資料或測試伺服器模擬載入失敗與重試，不改正式快照。
   - 唯讀估價單：`#v=1&q=RAW` 進檢視且網址原樣不重編；`#v=1&b=mid` 進檢視無 toast；截斷的 `#v=1&q=` 回編輯並 toast「分享連結無法讀取」；`#v=1`、`#v=1&b=不存在` 開預設配置的編輯模式；`#b=mid&cpu=4:22` 仍有舊版 toast。編輯 ↔ 預覽來回改過的內容保留，回編輯回到原捲動位置與按鈕；空單預覽只 toast。
   - 分享：stub `navigator.clipboard.writeText` 確認主按鈕／手機／估價單複製都是 `#v=1&q=`、可編輯連結是 `#q=`、複製清單最後一行是估價單連結。
   - 內容：拿 build 品項做連結、RAM 價格減 500 → 該列「現價 $X ▲500」、合計區「以現價計 ▲500」；不存在的品名 → 「已下架」與「N 項查無現價，以報價計」；任搭折品項 → 任搭折扣與估計實付；品名或 `n` 放 `<img onerror>` 只顯示成文字 (含分頁標題)。
   - 列印：使用瀏覽器列印，或支援的 CDP Page.printToPDF（printBackground、preferCSSPageSize，關掉 displayHeaderFooter）。用 pdftoppm 或 macOS PDFKit 轉圖，檢查白底、無按鈕、完整品名、列／合計不拆頁、跨頁表頭，以及手機頂部總額未重複印出。
   - 舊頁相容：把 `git show <改版前的 commit>:docs/index.html` 暫放 docs 開 `#v=1&q=RAW`，要開成編輯模式的分享單、無 toast、網址變回 `#q=`；測完刪掉暫存檔。
6. 保存桌面／手機預覽及驗收結果。區分本機通過與正式部署；更新技能不代表已推送、部署或啟用即時代理。
