      給電腦店老闆與業務：用這個網站幫客人報價
      • 估價單抬頭換成你的店名、業務、電話與 LINE；客人在手機上點電話就能撥號、點 LINE 就能加好友。
      • 以原價屋含稅報價為基準，填一個「本店價」，估價單會列出比原價屋省多少；也可以勾選隱藏原價屋單價，只給客人看本店價。
      • 可以加組裝費、灌系統、運費、到府收送等服務（填 0 顯示「免費」），以及客戶稱呼、報價有效期限與備註；店家估價單不會出現「帶到原價屋估價頁」。
      • 不用註冊：店家資料只存在你的瀏覽器，分享估價單時才寫進連結。老闆設定一次，按「複製店家設定連結」傳給同事，同事打開確認後就能套用。
      說明
      • 價格為原價屋線上估價頁的含稅價，不含作業系統、螢幕、鍵盤滑鼠等週邊；原價屋購買整機組裝免費。
      • 標籤：搭板專案 CPU 需與主機板同購才是此價；組裝價 / 裝機價 / 限搭機 需整機組裝才適用（買整機沒問題）；任搭折N 任搭其他商品再折 N 元，估價頁不會顯示、結帳才減；下殺 限時價。
      • 分享的估價單上的 ▲▼ 是「這張單的報價（分享當時的價格）」跟原價屋現價的差額；品名裡的「▼下殺到…」與下方的「價格異動」「下殺」「原價」是原價屋自己的近期調價標示，跟分享連結無關。
      • 相容性提示（腳位、DDR 世代、顯卡長度、散熱器高度）是從品名自動判讀的，僅供參考，下單前請再確認。
      • 切到「全部分類」可以另外加購原價屋其他分類的商品（螢幕、鍵鼠、喇叭耳機、作業系統，或第二顆 SSD、散熱膏等），同一類可以加好幾件；選件面板可以選分類，也可以跨分類搜尋。
      • 「複製分享連結」會把整張估價單（品名、當時價格、日期）存進網址，打開是一張唯讀的估價單：可以列印或存成 PDF，任何時候打開都看得到當初的報價，並標出原價屋現價的漲跌與已下架品項（搭板、裝機價等優惠結束但同型號還在賣的，改跟同型號的現價比）。按「編輯這張估價單」就能改單，改過的品項以現價計，再分享就是新的連結；「複製可編輯連結」打開直接是編輯畫面，「預覽估價單」可以先看看分享出去的樣子。
      • 按「全部清空」可以從空白開始，只分享單一零件（例如只分享記憶體）；按「重設為預設」可以復原。
      • 「帶到原價屋估價頁」會在新分頁開啟原價屋官方估價頁，預先選好這張單的品項與數量，可以接著在那邊列印或聯絡原價屋。那邊一律是原價屋現價；已下架的品項不會帶入，搭板、裝機價等優惠結束的改帶同型號現行品項。
      • 每小時自動抓取原價屋報價快照；預設配置的零件若下架，會保留原品項並標示「已下架」，請按「更換」改選。
