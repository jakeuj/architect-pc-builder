    說明
    • 價格為原價屋線上估價頁的含稅價，不含作業系統、螢幕、鍵盤滑鼠等週邊；原價屋購買整機組裝免費。
    • 標籤：搭板專案 CPU 需與主機板同購才是此價；組裝價 / 裝機價 / 限搭機 需整機組裝才適用（買整機沒問題）；任搭折N 任搭其他商品再折 N 元，估價頁不會顯示、結帳才減；下殺 限時價。
    • 分享的估價單上的 ▲▼ 是「這張單的報價（分享當時的價格）」跟原價屋現價的差額；品名裡的「▼下殺到…」與下方的「價格異動」「下殺」「原價」是原價屋自己的近期調價標示，跟分享連結無關。
    • 相容性提示（腳位、DDR 世代、顯卡長度、散熱器高度）是從品名自動判讀的，僅供參考，下單前請再確認。
    • 切到「全部分類」可以另外加購原價屋其他分類的商品（螢幕、鍵鼠、喇叭耳機、作業系統，或第二顆 SSD、散熱膏等），同一類可以加好幾件；選件面板可以選分類，也可以跨分類搜尋。
    • 「複製分享連結」會把整張估價單（品名、當時價格、日期）存進網址：任何時候打開都看得到當初的報價，並標出原價屋現價的漲跌與已下架品項（搭板、裝機價等優惠結束但同型號還在賣的，改跟同型號的現價比）；可以直接改單，改過的品項以現價計，再分享就是新的連結。
    • 每小時自動抓取原價屋報價快照；預設配置的零件若下架，會保留原品項並標示「已下架」，請按「更換」改選。

    個人製作的工具，非原價屋官方網站；價格以原價屋結帳為準。
