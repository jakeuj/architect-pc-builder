# 原價屋估價單 UI 優化

類型：新功能。此規格已由使用者在 2026-10-06 的實作要求確認。

## 為什麼做

七張起始配置卡占滿首屏；選件搜尋不支援多個關鍵字，也缺少排序與換件價差。改善從選起點到分享估價單的操作效率，保留既有風格與歷史報價。

## 要改什麼

- 用途先行（文書、入門遊戲、主流遊戲、高階），同用途並列平台；篩選不改單、選定收合。有效配置網址直接收合，首頁展開精簡選擇。
- 配置摘要顯示目前總計與修改狀態，保留本次頁面各方案草稿及分享單返回入口；分類使用可選 purpose/platform metadata。
- 搜尋正規化與多詞 AND、型錄群組篩選、原順序與現價排序；跨分類先排序再截取 300 件。
- 換件總計價差沿用實際選取規則與數量／鎖價／重複合併，不扣任搭折。
- 縮短介紹、配置說明收合、緊湊零件列、手機操作 44px、明確現價實付標示及動態底部留白。
- 手機估價單名稱全寬、緊湊 metadata 與頂部總額；列印維持表格。

## 影響範圍

網站 HTML/CSS、獨立的純 UI 邏輯模組、七份 build 分類 metadata、資料生成器與生成快照、coolpc 共用模板／腳本／測試／介面說明。共用正本與專案執行副本同步；保留既有未提交內容。

不改配置品項、價格公式、分享編碼、公開網址與 SEO metadata，不启用即時抓價，不跨重新整理保存草稿，不發布。
